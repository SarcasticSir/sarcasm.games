# Gaming news publisher

This directory is generated by `.github/workflows/gaming-news.yml`.

## Daily operation

- Runs at 06:17 in `Europe/Oslo` and can also be started manually.
- Reads ten configured RSS/Atom feeds.
- Handles failed sources independently.
- Normalises and groups duplicate coverage.
- Uses the OpenAI Responses API when `OPENAI_API_KEY` is available.
- Publishes a safe headline-only fallback if AI is unavailable.
- Writes `data/latest.json`, a dated archive file and the archive index.
- Commits only generated data and the idempotent homepage menu installation.

## One-time optional configuration

Add the repository Actions secret `OPENAI_API_KEY` to enable bilingual AI editing. The workflow variable `OPENAI_MODEL` can override the default `gpt-5-mini` model.

Without the secret, daily collection and publishing still run, but editions are explicitly labelled as fallback editions.
